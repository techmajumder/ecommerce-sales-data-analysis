E-commerce Sales Data Analysis

Project Overview
This project focuses on cleaning, analyzing, and visualizing a messy e-commerce sales dataset to extract meaningful business insights. The dataset contains real-world issues such as missing values, inconsistent formats, and noisy entries, which were handled using Python.

Problem Statement
Businesses often deal with unstructured and inconsistent sales data, making it difficult to derive insights. The objective of this project is to transform raw e-commerce transaction data into a clean, structured format and analyze it to support data-driven decision making.

Tools and Technologies
Python
Pandas
NumPy
Matplotlib

Data Cleaning Process
Handled missing and invalid values
Standardized column names and formats
Converted data types for accurate analysis
Created new features such as total sales and derived metrics

Key Analysis and Insights
Identified top-performing products and categories
Analyzed monthly sales trends
Examined customer purchasing behavior
Studied payment method distribution
Derived insights to support business decisions

Visualizations
Bar charts for category-wise and product-wise sales
Line charts for sales trends over time
Pie charts for distribution analysis

Project Structure

ecommerce_data_cleaning_and_analysis.ipynb – Complete analysis notebook

This project demonstrates the complete data analysis workflow, from handling messy real-world data to generating actionable insights. It highlights strong skills in data cleaning, analysis, and visualization.
